# **STM32F103C8T6 Custom Development Board**

## **Project Summary**

A compact **2-layer custom development board** based on the **STM32F103C8T6 (ARM Cortex-M3)** microcontroller.

The board was designed as a simple hardware platform for embedded systems development, testing, and firmware experimentation, with a focus on essential communication interfaces.

![STM32F103C8T6 Custom Development Board](https://github.com/KaisBergaoui/ESP32_S3_IoT_Board_v1.0/blob/main/media/05%20-%20ESP32_S3_IoT_Board%20F.png)

---

## **Features**

* **STM32F103C8T6** microcontroller
* 2-layer PCB
* USB interface
* UART interface
* SPI interface
* I²C interface
* JTAG programming/debugging interface
* Compact and simple development-oriented design

---

## **Applications**

* STM32 firmware development
* Embedded systems prototyping
* Communication interface testing
* Hardware and PCB design practice
* Educational and experimental projects
